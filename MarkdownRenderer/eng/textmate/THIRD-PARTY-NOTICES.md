## TextMate bundle resources

Some grammar registrations use the TextMate Bundle License. Unless an
individual source file says otherwise, the registered bundle license is:

> Permission to copy, use, modify, sell and distribute this software is
> granted. This software is provided "as is" without express or implied
> warranty, and with no claim as to its suitability for any purpose.

The precise bundle repository and commit for every copied grammar are retained
in `GRAMMAR-PROVENANCE.json`. Other registrations declare MIT, BSD,
Apache-2.0/Apache2, or GitHub License in their upstream `cgmanifest.json`; those
identifiers and exact source revisions are preserved verbatim in that file.
When an upstream manifest supplies a detailed copyright/license text, its
`licenseDetail` lines are also preserved verbatim on that registration rather
than being collapsed into only an SPDX-style identifier.
