# Shared SVG rules corpus.
#
# Each [case] names one input under inputs/ and the verdict every rule
# implementation must reach for those exact bytes:
#   worker    - the resvg worker preflight (native/src/svg_preflight), checked
#               by native/src/tests/svg_rules_corpus.rs
#   host      - ResvgMarkdownSvgRenderer.PrepareSource (inert-DOCTYPE
#               neutralization, SvgResourceBudget, SvgStaticSnapshot)
#   preflight - SvgPreflight, the host's direct OpenAsync preflight
# The host and preflight columns are checked by
# tests/MarkdownRenderer.Svg.Resvg.Tests/SvgRulesCorpusTests.cs.
#
# Verdicts are "accept" or "reject <class>: <detail>", where class and detail are:
#   worker    - the Reject variant and its exact message
#   host      - the MarkdownSvgFailureReason and the host preflight reason code
#   preflight - the MarkdownSvgException reason and its exact message
# Limits are the hard ceilings, which are also the host option defaults.
#
# When the sides disagree on accept versus reject, the case must carry a
# "difference" line saying why; both harnesses fail on an unexplained
# disagreement or on a stale difference note. Recording a difference does
# not endorse it: it documents current behavior so a change is deliberate.
# "seed" names the existing test the case came from.
